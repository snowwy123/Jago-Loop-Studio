# Drawing studies

Open .jago files from the app's Open button. GIFs and PNGs are previews. You can also open all the studies and samplers from Help (?).

- Bouncing-ball-smooth and Bouncing-ball-pixel: the same simple pencil animation in both styles. Try frame timing, squash/stretch and onion skin.
- Motion-study: a sketchy pencil pendulum using whole-layer Sway and a narrow pencil ribbon using Ripple. Choose each layer and load its settings from Motion > Edit settings for > Edit active layer settings.
- Cel-shading-study: a simple pencil ball, a clipped hatch shadow and small paper-colour highlights, following the base's gentle Sway. Hide/show each named layer to see its contribution.
- Brush-sampler: twelve animated samples in three columns and four rows, read across: pencil dab/chalk/flecks, stipple/continuous hatch/crosshatch, hard edge/dither/halftone dots, parallel lines/checkerboard/individual angled hatch stamps. The last sample demonstrates spaced tips that follow the stroke. All eleven built-in tips are included.
- Shape-sampler: eight editable animated shape examples. Both samplers open with live wiggle enabled; use Apply to layer or Apply to strokes to try another motion type.
- Line-study: four little waves drawn with Studio pen, Pencil, Marker and the adjustable Spray. Each brush has its own named layer.
- Starter-presets.jagopresets: eleven brush and eight motion presets. Import from the preset library.

These are simple tool demonstrations. They are not presented as scans or reproductions of Cameron's personal artwork.
