# Drawing studies

Open .jago files from the app's Open button. GIFs and PNGs are previews.

- Bouncing-ball-smooth and Bouncing-ball-pixel: the same simple pencil animation in both styles. Try frame timing, squash/stretch and onion skin.
- Motion-study: a sketchy pencil pendulum using whole-layer Sway and a narrow pencil ribbon using Ripple. Choose each layer and load its settings from Motion > Edit settings for > Whole active layer.
- Cel-shading-study: a simple pencil ball, a clipped hatch shadow and small paper-colour highlights, following the base's gentle Sway. Hide/show each numbered layer to see its contribution.
- Brush-sampler: eleven procedural tips in three columns, read across: pencil dab/chalk/flecks, stipple/hatch/crosshatch, hard edge/dither/halftone dots, parallel lines/checkerboard.
- Shape-sampler: editable filled shapes.
- Starter-presets.jagopresets: eleven brush and eight motion presets. Import from the preset library.

These are simple tool demonstrations. They are not presented as scans or reproductions of Cameron's personal artwork.
