Make your own brush pack

A stamp is a small shape or image you can paint with. For example, turn a drawn star into a stamp, then click to place one star or drag to paint a trail of stars.

  1. Create a stamp. Draw a small mark, then use Rectangle selection or Lasso to select it on its layer. Open Draw > Stamp brushes and choose Create stamp from selection. Or choose Import stamp image to use a PNG. A transparent background avoids a box around the stamp.
  2. Try it out. Choose your stamp under Stamp shape. Adjust size, spacing and colour, then click Use stamp brush (J) and draw. Spacing controls the gaps between repeated marks.
  3. Save the setup. Open Stamp presets, enter a name and choose Save stamp preset. A preset remembers the stamp image and settings shown in the dialog. It saves that stamp setup even if you last used a normal pen.
  4. Make a pack. Repeat for any other stamps, then choose Export library in Stamp presets. This downloads all your saved stamp and motion presets as one .jagopresets file, including the custom stamp images they use.
  5. Share or reload it. Use Import library in Stamp presets to add a pack, then click a saved stamp's name to use it.

Creating a stamp captures a still image, without its animation. Save movement separately with Save motion preset. Custom stamp images fit inside 128 × 128 pixels. A project holds 24 custom images; a library holds 30 stamp and 30 motion presets. Export a backup to keep or share. Use marks you own or have permission to share.

Stamp & motion presets

A preset is a saved setup you can use again. Save stamp preset remembers the stamp image, size, colour, opacity and stamp options shown below, even if a normal pen is selected. It does not save normal pen or pencil settings. Export library downloads all saved stamp and motion presets as one shareable pack. Import library adds a pack you already have.

Switch between Smooth and Pixel above the canvas at any time. Pixel size changes the block size without changing your strokes. Exports can use either style. The shapes button opens the extra shapes; Filled shape applies to new shapes.

The Move tool moves selected pixels when there is a selection, or the whole active layer when there is none. Paste returns artwork to its original position. Hold Shift to move in one direction. Fill can use the active layer or all visible artwork as a boundary. Erasing affects only the active layer. Use the layer lock to protect your work. Layer motion also moves imported images.

Stamp brush: J. Rectangle selection: U. Lasso: K. Copy/cut/paste selection: Ctrl C / X / V. Motion, shading and recovery live in the inspector tabs.

Motion study: the pendulum sways from its top pivot, the hatched ribbon ripples and a loose pencil line flutters. A soft shadow breathes twice per swing. Select their named layers to explore each motion.

Shading study: toggle the five named layers to explore the cast shadow, pencil base, stipple, hatching and highlight. Clipped shading follows the gently moving ball. Try Smooth and Pixel.
