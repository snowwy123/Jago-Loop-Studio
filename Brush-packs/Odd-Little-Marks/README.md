# Odd Little Marks, Vol. 01

16 original PNG brushes, 3 motion presets, and permission to make a mess.

Brush pack revision 1.4. The brushes are unchanged from revision 1.1. These instructions follow Jago Loop Studio v1.1.5; the brush data also works in v1.1.3 and later.

A separate experimental brush pack for **Jago Loop Studio v1.1.3 or later**, by Cameron Jago Lis Illustrates. Try dry crumbs, scratchy ink, broken rings, loose fibres, dusty shading and a few cheerful oddments. Mix them together, change the colours and see what happens.

## Get the brushes into the studio

1. Extract this ZIP somewhere you can find it.
2. Open Jago Loop Studio. In **Draw**, choose **Stamp brush (J)**, or press **J** while drawing. In the Stamp brushes panel, scroll down to **Stamp presets**.
3. Choose **Import library** and select **Odd-Little-Marks.jagopresets**.
4. Close the preset window. In the Stamp brushes panel, choose any name from **Brush > Imported presets**, then draw. All brushes are available immediately; their images and settings load automatically when chosen.

You only need to import the library once in each browser or Windows app you use. The custom PNG images are already inside the pack file, so you do not need to import them individually as well. Export your existing library first if you would like a backup.

**Already have this pack?** The artwork is unchanged from revision 1.1, so there is no need to reinstall it. Reimporting the same pack skips identical presets and identifies matching Earlier presets as Imported. If upgrading from the very first version, Sunday Stripes, Kitchen Tiles, Soft Static and Sideways Chalk were replaced by four original PNG brushes. Remove those four older entries if you no longer want them. Export your library first if you would like a backup.

## Have a little play

- Open **Try-the-marks.jago** with the studio's **Open** button for an editable brush menu. Each row of marks has its own layer. The text and cards are on a locked layer called **The page**.
- Change **Size**, **Opacity** and **Colour** beneath the preview to make a brush your own. These presets use your drawing colour; leave **Keep original image colours** off for coloured marks.
- Use **One stamp per click** for a single ring, bubble or sparkle. Use **Along a stroke** to paint a trail. **Spacing** changes the gaps between repeated marks.
- Try **Stamp rotation**, **Rotate along the stroke**, **Scatter** and **Size variation** under **Rotation & variation**. Dry Little Drag, Loose Ends, Wobbly Teeth and Loose Stitches already follow the direction you draw.
- All sixteen brushes use custom PNG images. **Size** scales the whole stamp, including its texture. They do not have the separate Pattern size or aligned Continuous pattern controls of the built-in patterns. Use Along a stroke and Spacing to build a trail of marks.
- At the bottom, choose **Save as new preset**, enter a name and choose **Save preset**. Your version appears in **Your saved presets**; the original stays unchanged. **Reset stamp defaults** is beside it and resets stamp options while keeping the current stamp image, size and colour.

**Stroke feel & motion** contains smoothing and the stamp-motion placement option. **Edit brush** lets you change or import a stamp image. Mirror and Wiggle new marks are grouped under **Drawing options**.

See **Brush-guide.md** for ideas for every brush. **Brush-menu.png** and **Brush-menu.gif** show the brushes rendered by the studio itself.

## Give the marks some movement

The library also includes three optional motion presets. Choose a name under **Motion preset** in the Motion panel:

- **Gentle Fidget:** classic line boil for a little restless movement. Adjust Amount and Redraws per second in the Classic controls to taste.
- **Paper Breeze:** a small flutter, pinned at the start of the stroke or left of the layer.
- **Grain on the Move:** texture crawl for shifting stamp grain. This can suit Paper Freckles and Crumb Collector; recognisable shapes such as rings and sparkles may look more jittery.

Choosing a motion prepares new marks. To animate existing artwork, select its layer and choose **Apply to strokes** or **Apply to layer** in Motion. Texture crawl affects stamp texture. Brush presets and motion presets are separate, so choosing a brush does not automatically choose its movement.

## A couple of useful limits

The studio holds **30 stamp presets and 30 motion presets** in its library. This pack adds 16 and 3 respectively. If you have lots saved already, export a backup and make room before importing it. Importing an unchanged pack again skips identical presets. Different setups with the same name are kept separately.

Each drawing project holds **24 different custom stamp images**. This pack uses 16. Images are included only when used and reused when you select the same brush again, including in the sampler, which already contains all sixteen. You do not have to add images one at a time before drawing. If a project uses 24 different images, its existing stamps still work; save it and start another drawing to use additional images.

The Brush dropdown separates **Default brushes**, **Imported presets**, **Your saved presets** and **Earlier presets**. Custom images without a matching library entry appear under **In this drawing**. The motion-preset dropdown uses **Default settings** for its built-in setups. Tweaking a chosen preset labels it **(modified)**. Save it under a new name to keep your version. To remove presets, open Stamp & motion presets, tick the entries and choose **Delete selected**, or start with **Select imported**. **Undo removal** restores the last deletion during the current session. Removing library presets leaves images and marks in drawing projects intact.

The PNG tips are 128 x 128 pixels, but you can paint with them at sizes up to **160 px**. The preview keeps its scale steady while you adjust Size. Transparent margins in an image count towards the brush footprint; pressure and size variation can change individual marks. They also work as source images in other software that can import transparent PNG stamps, although the saved Jago settings and motion do not transfer. Tiny pixel-art canvases may lose the finer fibres and grain, so try a larger brush or a bolder tip.
